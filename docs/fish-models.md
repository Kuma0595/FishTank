# 用户鱼模型接入

## 资源

- 用户提供的 Tripo GLB 原件：`assets/source/uploaded-fish.glb`。
- 网页实际加载：`public/models/fish/uploaded-fish.glb`。
- 与模型一致的渲染缩略图：`public/models/fish/uploaded-fish.webp`。

原件 3,102,696 字节、108,920 个三角面、64,006 个顶点，包含一张 1024 × 1024 JPEG 基础色贴图；不含骨骼和动画。网页轻量版 1,064,256 字节、19,604 个三角面，保持原有纹理坐标和内嵌贴图，不依赖在线解码器或外部贴图 URL。

原件保留在源码目录中，不会被 Vite 复制到网页构建产物。重新生成轻量版：

```sh
node scripts/optimize-fish.mjs assets/source/uploaded-fish.glb public/models/fish/uploaded-fish.glb
```

简化目标为原面数的 18%，最大误差参数为模型半径的 0.001。每份新模型仍需目视检查轮廓、鱼鳍、贴图与动画。

## 在应用中使用

用户已确认上传模型为白云金丝。素材库的白云金丝卡片及居民列表直接显示模型缩略图，点击添加后自动使用该 GLB，无需选择鱼种、手动应用或管理映射。宝莲灯使用独立的用户模型，总鱼种数为 11 种，其他鱼种保留各自造型。

鱼模型归属由 `src/fish-assets.ts` 中的 `fishModelForSpecies` 固定声明，不再保存到鱼缸状态。旧存档的 `modelSpecies` 字段会在读取时丢弃，原有鱼种、数量及造景保持不变；旧映射不会再将模型应用到其他鱼种。新存档不含此字段。

## 运行与动画

`src/fish-model.ts` 使用 GLTFLoader 异步加载模型，烘焙原始节点变换、居中并统一长度，将原件的负 Z 朝向旋转为鱼运动系统的正 X 朝向。`src/fish-assets.ts` 保存资源路径、朝向校正和长度比例。

这是一份静态模型。新增的程序化顶点变形会让身体与尾部沿横向小幅波动，并修正表面法线；每条鱼使用不同的相位，避免完全同步。现有游动、转向、喂食行为由鱼演员外层对象继续驱动。这不是新增了骨骼或专业游动动作，胸鳍等局部动作仍有提升空间。

同一鱼缸中的多条鱼共享加载结果、几何与纹理，每条鱼独立拥有材质和动画参数。移出鱼只释放该鱼的材质；关闭鱼缸时统一释放共享资源。加载完成后会检查鱼是否仍然存在，避免已删除的鱼被异步回调重新加入。资源加载失败时保留原造型并给出提示。

`src/fish-model.test.ts` 覆盖坐标校正、纹理坐标保留、共享资源生命周期、延迟加载取消和发布资源面数／体积。`src/fish-model.test.ts` 还覆盖两份模型各自只属于白云金丝与宝莲灯，`src/model.test.ts` 覆盖旧存档映射移除与居民／造景保留。

## 孔雀鱼默认造型

`src/guppy.ts` 为孔雀鱼单独生成闭合曲面鱼体：肩部饱满、腹部柔和、尾柄收窄，头部带小型玻璃质眼睛、上翘嘴与弧形鳃盖。大扇尾、背鳍、臀鳍均为细分膜面，尾缘与鳍条在深度方向有轻微起伏；鱼鳍材质包含透明度渐变、细鳍条和不规则色斑。

银蓝色身体使用程序化鳞片贴图、微凹凸、清漆与虹彩材质，环境反射补足鳞片光泽。红橙、蓝白、黄黑三个品系由鱼的 uid 稳定选择，重新加载存档或恢复默认造型不改变个体配色。所有贴图在本地生成，无需下载新模型或图片。

身体与尾柄使用连续顶点波动，尾端叠加柔和膜面颤动，胸鳍独立摆动；频率随实际游速变化。当前仍是实时程序化动画，没有使用电影制作中的骨骼绑定或流体模拟。白云金丝与宝莲灯固定使用各自的用户模型，其余八种鱼继续使用原有默认造型，孔雀鱼始终使用新版曲面彩尾造型。

`src/guppy.test.ts` 检查曲面朝外法线、有效 UV、尾柄比例、鳍根连续性、膜面深度、面数预算和稳定配色。实际 WebGL 材质编译、缸内显示及动画另经浏览器目视验证。


## 宝莲灯（Cardinal tetra）

新增独立热带鱼种 `cardinal`（宝莲灯，Paracheirodon axelrodi），不替换已有红绿灯或白云金丝。素材卡片、搜索、热带鱼分类与居民列表均支持宝莲灯，添加后自动加载模型，沿用已有游动、喂食、撤销／重做、自动保存与 JSON 导入／导出。

- 用户原始 FBX 与 JPEG 完整保存在 `assets/source/cardinal-tetra/`，包含原件的拓扑数据。
- 网页模型：`public/models/fish/cardinal-tetra.glb`，795,164 字节，19,042 个渲染三角面；无额外减面，JPEG 按原始字节内嵌。
- 模型实拍透明缩略图：`public/models/fish/cardinal-tetra.webp`。
- FBX 网格转为 GLB 时按 WebGL 的三角面格式导出；原始拓扑以 FBX 原件为准。转换烘焙节点变换，保留法线与 UV 接缝，并转换纹理 V 方向以匹配 glTF。
- 模型原始朝向为负 Z，运行时绕 Y 轴旋转 -90°，与正 X 前进方向一致。模型长度为 `1.22 × 0.46`，尾部沿用共享的程序化摆动。原文件不包含骨骼或动画。

重新生成网页模型（不需要 Blender 或外部转换服务）：

```sh
node scripts/convert-fbx-fish.mjs assets/source/cardinal-tetra/tripo_convert_92270b96-0002-4256-85f2-b7c221a0a452.fbx public/models/fish/cardinal-tetra.glb
```

转换脚本专用于带外部 JPEG 的静态 FBX；遇到骨骼、变形动画、多材质或纹理变换时明确报错，避免静默丢失数据。网页面数／体积、内嵌贴图与原图字节一致性、物种独立映射和新旧鱼种混合存档均由测试覆盖。
